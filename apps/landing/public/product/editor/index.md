# Editor

Write with your whole team. In real time. Blocks, shortcuts, and live editing. Even when you are offline.

## Write without friction

- Type, don't click: Markdown shortcuts and a slash menu for every block.
- Rich blocks: tables, code, images, callouts, tabs, and more.
- Connected docs: link to other entries as you type.

## Better together

- Live editing: see every change as it happens.
- Work offline: keep writing without a connection. Changes sync when you are back.
- Every version saved: compare, restore, or publish any earlier version.
