# Extensions

A workspace that fits you. Just add extensions. Install what you need, or build your own with panels, views, and actions.

## Ready to install

- Andesine Pages: publish any collection as a docs site.
- GitHub Sync: keep your content in sync with Markdown in your repo.

## Build your own

- Panels: add a side panel next to every entry, with your own tools and settings.
- Element views: show your own blocks right in the editor, just as your site renders them.
- Actions and menus: add commands to blocks, menus, and the toolbar.
- A backend: run server code and store data for your extension.
