# AI and agents

One source for every agent. And every answer. Connect Claude, ChatGPT, Cursor, and more. They see only what you allow.

## Ask, and get answers

- Answers with sources: every answer links to the pages it came from.
- Search as you type: find any page in a few keystrokes.
- Current or published: ask about drafts, or only what is live.

## Bring your own agent

Connect any AI app through MCP: Claude, ChatGPT, Cursor, VS Code, and Claude Code.

- Read and write: agents search, read, and update entries for you.
- Same rules as people: an agent sees only what its person can see.
- For coding agents too: run the server locally, or install the Claude Code and Cursor plugin.
