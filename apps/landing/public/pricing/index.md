# Pricing

Pricing that grows with you. Starting at free. Free for small teams, Pro as you grow, or host it yourself.

## Free

$0 a month.

- Up to 3 members, all admins
- 50,000 API calls and 5,000 AI credits a month
- GitHub Sync, MCP, and the API
- A hosted docs site, with a badge
- 7-day version history and 1 GiB of image storage

## Pro

$12 USD per seat per month.

- Unlimited members, default and custom roles, groups, and restricted collections
- 150,000 API calls and 15,000 AI credits per seat, shared across the workspace
- Extra usage: $1 per 50,000 API calls or 5,000 AI credits, with a spending limit
- Custom domains for hosted sites, with no badge, and private GitHub repositories
- 30-day version history and 50 GiB of image storage
- Agents never need a seat.

## Self-hosted

Free. The source is on GitHub, and the default setup includes Pro features.
