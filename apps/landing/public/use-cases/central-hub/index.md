# Centralized hub

One source of truth. For people and agents. Keep facts, guides, and rules in one place. Your apps and agents read them through MCP and the API.

## Bring your own agent

Connect any AI app through MCP: Claude, ChatGPT, Cursor, VS Code, and Claude Code.

- Read and write: agents search, read, and update entries for you.
- Same rules as people: an agent sees only what its person can see.
- For coding agents too: run the server locally, or install the Claude Code and Cursor plugin.

## Change it once

- Answers with sources: agents and people get the same answers, with links.
- Content API: your apps read the same content as your agents.
- Webhooks: tell every system when something changes.
