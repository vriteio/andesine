# Product docs

Docs your whole team can write. And readers love. Write in one editor, then publish a site, sync with GitHub, or ship through the API.

## Easy to write

- Type, don't click: Markdown shortcuts and a slash menu for every block.
- Rich blocks: tables, code, callouts, tabs, and more.
- Live editing: write and review together, in real time.

## Published your way

- Live in a click: turn your docs into a site with search and AI answers.
- Sync with GitHub: keep Markdown or MDX in your repo, in both directions.
- Content API: fetch your docs into any website or app.
