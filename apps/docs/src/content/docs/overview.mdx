Andesine is an open-source content workspace for product documentation, internal knowledge bases,
technical publications, and in-product content.

## The workflow

<Steps>
  <Step title="Write">
    Draft rich-text content with your team and keep editorial work in one workspace.
  </Step>
  <Step title="Structure">
    Add properties, named fragments, and shared schemas so each document matches your product.
  </Step>
  <Step title="Publish">Publish saved versions through the API and customizable channels.</Step>
</Steps>

## Choose how to run Andesine

Use the managed cloud app for the fastest start, or run the source from
[GitHub](https://github.com/vriteio/andesine) on your own infrastructure.
