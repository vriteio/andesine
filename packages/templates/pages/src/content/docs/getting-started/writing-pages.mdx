Each `.md` or `.mdx` file in a files source is one page. The file path gives the
URL and the place in the navigation.

## URLs and navigation

- `guides/setup.md` has the URL `/guides/setup/`.
- `guides/index.md` has the URL `/guides/`. It is the landing page of the
  `guides` group.
- A folder without an index page becomes a group with a label from the folder
  name.

Items sort by `order`, then by path.

### Folder files

A folder can have a `meta.json` file in the [Fumadocs](https://fumadocs.dev)
format. A `meta.json` file in the source root applies to the top level.

```json
{
  "title": "AI agents",
  "pages": ["connect-an-ai-app", "local-server-and-plugin"]
}
```

- `title` is the label of the folder in the navigation. It replaces the label
  from the folder name or from the index page.
- `pages` lists the file names without extension, and the subfolder names, in
  order. Items that are not in the list come after it and sort as usual.

The build stops when a `meta.json` file is not valid JSON, or when `pages` has a
name that is not in the folder.

## Frontmatter

| Field              | Default  | Description                                                                                  |
| ------------------ | -------- | -------------------------------------------------------------------------------------------- |
| `title`            | Required | The page title.                                                                              |
| `description`      | None     | The page summary.                                                                            |
| `slug`             | None     | A URL path that replaces the file path.                                                      |
| `navigationLabel`  | `title`  | The label in the navigation.                                                                 |
| `navigationHidden` | `false`  | Removes the page from the navigation.                                                        |
| `searchHidden`     | `false`  | Removes the page from search.                                                                |
| `order`            | `0`      | The position among items in the same group.                                                  |
| `toc`              | `true`   | Shows the table of contents.                                                                 |
| `layout`           | `docs`   | `docs`, or `wide` for a page without a ToC.                                                  |
| `updatedAt`        | None     | The date of the last change, e.g. `2026-09-27`. It shows in the page footer and the sitemap. |

The build stops when a field is not valid, or when two pages use the same URL.
