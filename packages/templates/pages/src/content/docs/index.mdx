This site is an Andesine Pages template. You own all of its files: the
configuration, the layouts, the styles, and the content.

## How the site works

- `andesine.config.ts` sets the site name, the brand colors, the links, and the
  content sources.
- The pages in `src/content/docs/` are a files source. Each Markdown or MDX file
  is one page.
- `src/layouts/page.astro` renders each page. It receives the page data from
  `@andesine/pages`.
