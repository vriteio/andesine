title: Customization
description: Change the layouts, components, and styles of the site.
order: 2
---

All the files of the template are yours to change:

- `src/layouts/page.astro` renders each page.
- `src/components/` holds the styled primitives and layout components.
- `uno.config.ts` and `src/styles/global.css` hold the theme and base styles.
