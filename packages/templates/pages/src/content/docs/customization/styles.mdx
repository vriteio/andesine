The template uses UnoCSS with the design language of the Andesine app.

## Brand colors

Set `brand` in `andesine.config.ts`. `uno.config.ts` reads these colors into the
`primary`, `secondary`, and `tertiary` theme colors. The brand gradient goes from
`secondary` to `primary` and back to `secondary`.

## Components

The styled components are in `src/components/`. Their default classes start with
`:base:`, so a `class` prop overrides them. Change the components directly: they
are part of your site.
